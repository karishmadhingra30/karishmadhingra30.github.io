# Karishma Dhingra — Portfolio

The source for [karishmadhingra30.github.io](https://karishmadhingra30.github.io), a recruiter-friendly portfolio of selected work across practical AI products, public-interest technology, and safety-oriented systems.

## What is included

- Eight featured projects with direct repository links and live demos only where available.
- Plain-language project context, technical focus, and prototype/safety status.
- Responsive, dependency-free static HTML, CSS, and JavaScript suitable for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Update the portfolio

Edit `index.html` to add a featured project or replace an existing card. Keep each project description concrete, link to code, and only add a demo link after verifying it works publicly.
