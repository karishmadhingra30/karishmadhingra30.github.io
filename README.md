# Karishma Dhingra — Solutions Engineering portfolio

The source for [karishmadhingra30.github.io](https://karishmadhingra30.github.io): a portfolio for Solutions Engineering, Applied AI, Sales Engineering, Customer Success Engineering, and GTM Engineering roles.

## Positioning

Karishma is a customer-facing technical builder with five years of consulting experience. The site presents evidence of the work these roles require: leading discovery, mapping workflows, translating requirements into technical plans, building demos and prototypes, and closing feedback loops between customers, Product, and Engineering.

## What the site includes

- Eight selected solution builds with direct repository links and verified live demos where available.
- Project context that explains the customer problem, technical trade-offs, and prototype or safety status.
- Filters for Applied AI, Customer Workflows, and Trust & Evaluation.
- A dependency-free, responsive static site that runs on GitHub Pages.

## Update a project card

Project cards are intentionally easy to maintain. When a repository gains a live demo, a stronger README, or a new visual walkthrough:

1. Update its card in `index.html` with the verified live URL and a concise outcome-focused description.
2. Keep the code link pointed at the canonical repository.
3. State prototype limitations or synthetic-data status plainly; credibility is more useful than an overbroad claim.
